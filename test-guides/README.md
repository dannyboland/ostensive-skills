# test-guides

Local copies of style guides and craft books used to test `quote-review`.
Everything in this folder except this file is ignored by git: these are
copyrighted books and must not be committed or published.

Use DRM-free EPUB or PDF files. Run the scripts from a scratch directory and
point at the file here, for example:

    quotereview.py fetch --allow-local /path/to/repo/test-guides/steering-the-craft.pdf
